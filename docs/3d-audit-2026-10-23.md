## Blockers
1. **No hero GLB assets** — used procedural fallbacks (PBR boxes, CanvasTexture labels, Sprite billboards). Need GLB source pack or Kenney/PolyHaven + Mixamo rigs for NPCs.
2. **No threejs-game-skills** — built `world3d.ts / player.ts / npcs3d.ts / input.ts / ThreeCanvas.tsx` directly; workflow documented for later skill injection.
3. **Shadow cost on mobile** — kept 2048×2048 PCFSoft for courtyard, 1024 for interiors; exposure capped, pixelRatio ≤2, should be tiered to 1024/512 on low GPU detected via renderer.capabilities.
4. **Zone stitching** — exits currently via trigger → store.interact → shared TRAVEL; no seamless streaming. Street is a corridor connecting courtyard↔shop/café/metro/dombyta; apartment is separate.
